# Portfolio roadmap

This repository is Project 1 in a four-project sequence based on the AI Career Training Plan.

## Current milestone — Project 1: EDA + data quality

- [x] Public source dataset and reproducible download script
- [x] DuckDB SQL load with tolerant type conversion
- [x] Required-field, missing-value, duplicate, range, ordering, and chronology checks
- [x] Streamlit dashboard with quality score and EDA
- [x] Data dictionary, tests, linting, and GitHub Actions
- [ ] Add a screenshot and a short findings section after reviewing the dashboard
- [ ] Deploy the dashboard with Streamlit Community Cloud or another host

## Next repositories

### Project 2 — Predictive model

Build a baseline-to-production-style supervised model with cross-validation, leakage checks, error analysis, a model card, and a business-facing write-up.

### Project 3 — Governance RAG assistant

Build a cited RAG assistant over public policy or documentation. Measure retrieval quality and test unsupported answers, prompt injection, privacy, and responsible use.

### Project 4 — Deployed AI capstone

Package the strongest model or RAG work behind an API and simple front end. Add Docker, versioning, monitoring, an architecture diagram, and a one-page case study.

The goal is not to collect repositories. The goal is to publish 2–3 projects that can be explained confidently in an interview.
